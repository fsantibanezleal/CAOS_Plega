# v0.02 public-boundary review

The redesign retains the public, static GitHub Pages boundary. It introduces no account system, backend, runtime credential or external font request. Project and assembly storage remain on the device; shared fragments continue to exclude local notes and completion state. The two new interface font families are unmodified OFL assets, pinned to the Google Fonts source revision recorded in `frontend/public/fonts/provenance.json`, with complete license notices distributed beside them.

Cut profiles accept only four enumerated patterns, integer density 1–6 and material web 1–5 mm. The project parser and independent Python pipeline reject extra properties, malformed values and unsupported counts. Projects remain bounded to 128 KiB and sixteen modules. Direct manipulation uses the same analytic geometry validation as the rest of the app; a drag previews separately from saved data and commits once. Cutwork meshes use a bounded immutable cache. FOLD intersection processing rejects excessive cut-graph density before its pairwise work. Export adapters validate aperture coordinates as well as exterior face coordinates.

The working-source review inspected all current source/data/license files and every reachable blob in the fetched Git history for credential patterns, private operator paths, management references and private network addresses. It found no matches. The locked dependency audit reported zero known vulnerabilities and no unknown package license declarations. These are bounded inspections, not a proof against every possible vulnerability. Final delivery must also scan the exact deployed artifact and verify its revision, file hashes, bundled licenses, same-origin resource behavior and current GitHub security settings.

The original v0.01 assets, designs, history and release are preserved. New cut profiles and compositions were authored for this project; linked paper-engineering research is contextual and its artwork/templates are not redistributed. The geometric certificate remains a rigid zero-thickness model. It does not certify paper strength, adhesive performance or physical assembly.
