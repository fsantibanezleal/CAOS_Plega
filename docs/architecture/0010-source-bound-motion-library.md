# Source-bound continuous model library

Date: 2026-10-03. Status: accepted for implementation under the user's instruction.

The previous release offered one complete crane. Source links and diagrams cannot
replace the requested animation for each origami. The library must grow from
independently admitted construction sequences, without cosmetic variants inflating
the model count. The original workshop, structure studies and helper folds remain.

Use sanitized geometric trajectories from licensed sources and a deterministic
standard-library compiler. A fold is a rotation of the actual moving faces about
its actual crease. A turn and a flip are rigid motions. Reject unknown actions,
incorrect endpoints, changing paper area and stretched rigid triangles. Publish
the source hash, operation mapping, licenses and exact output hash with each model.
Simulator replay is an optional authoring command with a pinned checkout and
NumPy 2.2.6; routine build and release need no simulator, inference or provider key.

Runtime loads only the URLs in the compiled lesson manifest and verifies SHA-256
before parsing. The existing static CSP remains. The library is the entry view,
with categories, search and geometric previews. Selecting a model opens its own
lesson, continuous playback, individual-step playback, EN/ES text and generated
before/after illustrations. Desktop step lists scroll inside their panel; phone
lessons remain reachable through page scroll. Theme and language preferences may
be kept locally. Existing areas and data are retained.

This source set initially admits 16 reconstructions plus the preserved crane.
The requested thousand-model library remains open. Upstream reported success is
not sufficient for admission. Reconstructed rigid geometry is not a certificate
of physical foldability or collision-free paper motion.
